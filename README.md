# Musubi (coaching)

Private Shibari atelier: tie library, consent-first safety, and a studio that reads **photos and video** of a consenting adult partner, then coaches the next wrap.

This repo is the source. The live app is meant to run **in Grok**. Journal stills stay on-device unless you tap Analyze (compressed frames go to Grok, then a local auditor can veto unsafe advice).

## Studio camera

- Live camera with continuous focus, optional torch, and wrap-framing guides (torso / back / hands / legs)
- Burst stills: three frames, keep the sharpest
- Record a short clip; the best three frames (sharpness + exposure + rope signal) are sent to the coach
- File Photo / Video still work when the in-app camera is blocked

## Not in this app

Neck restraint, breath play, and full suspension how-tos. Partial lift is a primer only.
